LUMEN — Design language

The dark theme already in use across the repo, extracted into a token system. Every color, type step, spacing unit, and component below is rendered with var(--…) from design/tokens.css — nothing is hardcoded.
Theme: dark  ·  Source of truth: design/tokens.json  ·  Generated sheet: design/tokens.css
How to read this page. This is the human view. The machine source is design/tokens.json; design/tokens.css is generated from it. Any UI should consume the CSS variables and never reintroduce raw hex/px — the token linter (scripts/lint-tokens.mjs) enforces that.
